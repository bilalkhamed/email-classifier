# Spam Classifier Web App

A simple web app that classifies email or text content as **Ham** (legitimate) or **Spam** using a Multinomial Naive Bayes model.

---

---

## Tech & Libraries

### Backend (Server and ML)

- `FastAPI & Uvicorn` – for server
- `scikit-learn` – machine learning (Count Vectorization and Multinomial Naive Bayes)
- `pandas` – data handling
- `joblib` – save/load models

### Frontend

- `React`
- `TypeScript`
- `Tailwind CSS`
- `Axios`

### Dataset

> [FAISAL QURESHI on Kaggle](https://www.kaggle.com/code/mfaisalqureshi/email-spam-detection-98-accuracy/input)
